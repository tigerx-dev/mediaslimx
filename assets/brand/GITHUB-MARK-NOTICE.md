# GitHub mark

`github-mark.svg` is a recolored copy of GitHub's `mark-github-24.svg` from
[Primer Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-24.svg)
(retrieved 2026-10-19). `github-mark.png` is its local 36×36 render; the same
PNG is embedded in the Windows startup window.

The mark is used only on a button that opens the MediaSlim X GitHub repository.
GitHub retains the rights to its logo; this use does not imply endorsement.
The project's MIT license does not purport to relicense the GitHub mark.
