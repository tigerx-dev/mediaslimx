# Actual interface captures / 真实界面素材

这些 1600 × 1000 截图来自独立 WSL/Linux 服务的真实扫描、默认导出任务和图片前后预览。媒体全部由 `scripts/showcase-fixtures.py` 自行生成，不含用户文件、FIRANO 素材或其他项目资源。输入目录位于新建的 `/tmp/MediaSlimX-Demo-*` 下，不包含真实用户名和私有项目路径。

The 1600 × 1000 screenshots show a real scan, default export and original/result image preview on an isolated WSL/Linux service. All input media is generated by `scripts/showcase-fixtures.py`; it contains no user files, FIRANO material or assets from other projects.

合成素材包括 JPG、带透明通道的 PNG、静态 WebP、普通 SDR H.264 MP4 和普通 PDF。使用“均衡”、保持原尺寸、导出到新目录；全部原件哈希在处理后重新校验一致。PDF 本例实际无收益，因此保留原件，不能据此宣传所有 PDF 都会变小。

The synthetic set includes JPG, alpha PNG, static WebP, ordinary SDR H.264 MP4 and a plain PDF. It uses Balanced, original dimensions and export to a new directory. Every original hash was checked after processing. This PDF produced no saving and was retained unchanged.

**所有体积数字仅代表这组自制演示素材的实测结果，不代表真实网站收益、固定压缩比例或页面加载收益。** 截图未改写界面状态或数据；未拍摄浏览器地址栏、访问令牌或个人桌面。原始无旁白 WebM 保存在忽略的 `.mediaslimx/showcase/<run-id>/raw-demo.webm`，不加入应用运行包。

**The measurements apply only to this synthetic set. They are not real website savings, a guaranteed compression ratio or a page-load benchmark.** Screenshots retain the actual interface state and data. The browser address bar, access token and personal desktop are excluded. The raw silent viewport recording remains in ignored `.mediaslimx/showcase/<run-id>/raw-demo.webm` and is not bundled with the app.

## Reproduce / 复现

开发环境需要项目自己的 Linux Python 环境（含可选 PDF 模块）、完整宿主 FFmpeg、Chrome 和项目既有 Playwright。它们只用于开发捕获，不给产品新增 Node/Playwright 运行依赖。录屏辅助程序可安装到忽略目录：

The development capture uses the project's Linux Python environment (including the optional PDF module), host FFmpeg, Chrome and the existing Playwright installation. Node/Playwright are not app runtime dependencies. Install the development recorder in the ignored tools directory:

```bash
PLAYWRIGHT_BROWSERS_PATH="$PWD/.mediaslimx/browser-tools/browsers" \
  node .mediaslimx/browser-tools/node_modules/playwright/cli.js install ffmpeg
node scripts/capture-showcase.cjs --output "$PWD/.mediaslimx/showcase/new-reviewed-assets"
```

脚本拒绝覆盖已有截图；每次使用新的合成媒体、独立数据目录和空闲回环端口，不访问 8765/8766 上已有服务。结束后关闭自己的浏览器和服务，保留本次合成素材和私有证据供复核。复现结果可能随 Python、Pillow、FFmpeg、PDF 模块及系统版本变化；以新生成的 manifest 为准。这些是桌面视口捕获，不代表干净 Windows 验收或实体手机验证。

The script refuses to overwrite existing captures and uses new media, service data and a free loopback port for each run. It never contacts existing services on 8765/8766. It stops its own browser and service afterward and retains synthetic fixtures and private evidence for review. Byte results may vary with runtime versions; use the newly generated manifest. Desktop viewport capture is not clean-Windows or physical-phone validation.
