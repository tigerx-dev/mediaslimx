## MediaSlim X · VERSION

图片、MP4 与 PDF 批量压缩工具

MediaSlim X 是免费开源的图片、MP4 与 PDF 本地批量压缩工具。Windows 通过独立窗口使用中英文工作台；选择媒体目录或拖入文件，查看扫描、设置处理方式，再检查逐文件的实际结果。适合网站素材整理，也可处理准备上传的素材。

### 下载与启动

- Windows x64 用户下载本 Release 的 **`MediaSlimX-VERSION-windows-x64.zip`**，完整解压，双击 `MediaSlimX.exe`。下载大小：**填写该版本实测 MiB**，完整解压：**填写实测 MiB**。
- 自带 Python、图片/PDF 引擎和精简 FFmpeg/ffprobe，运行不需要首次下载环境，不使用在线库更新器。请保留 EXE 和 `_internal` 整个目录；不要在 ZIP 预览窗口里直接启动。
- 需要已安装的 **Microsoft WebView2 Evergreen Runtime**；不捆绑完整 Runtime，缺少时提示人工安装，不自动下载或静默改用外部浏览器。离线启动要求该 Runtime 已存在。
- 双击打开工具自己的窗口，默认仅监听 `127.0.0.1`。任务进行中关闭窗口时先确认；选择“保留进度并退出”会等待当前文件安全收尾，保留已完成结果和剩余清单，下次由用户主动继续。其他项目进程不受按名称查杀。
- **Code → Download ZIP / Source code (zip)** 是给开发者的源码，需要按 README 安装依赖；它不包含可双击的便携程序。
- 配套 `third-party-materials.zip` 用于查看对应源码、许可证和构建材料，运行无需下载它。校验文件：`MediaSlimX-VERSION-SHA256SUMS.txt`。

### 这一版可以做什么

1. 扫描运行设备上明确选择的媒体目录；或拖入文件、整个文件夹，保留相对目录结构。按 JPG、PNG、WebP、MP4、PDF 选择待处理项。
2. 选择画质优先、均衡、体积优先；默认保持尺寸。主动限制最大宽高时等比缩小，不拉伸、不裁切、不放大。PDF 不套用图片画质或尺寸设置。
3. **默认导出至新目录，保留原件、文件名、实际格式和目录结构**。原目录更新需主动选择备份覆盖；普通 PDF 不允许无备份覆盖。浏览器导入始终仅导出。
4. 看实际进度、取消剩余文件、查看逐文件结果、图片/视频预览、CSV 报告和持久任务历史。无收益保留原件，失败与不支持会列出原因。
5. 备份覆盖后支持单文件、整批恢复；当前文件发生变化时跳过冲突。归档整理列表，导入副本空间管理单独释放本实例副本，清理前说明影响并确认。

### 支持范围与限制

- JPG/JPEG、PNG、静态 WebP；普通 MP4 仅支持 H.264 8 位 SDR yuv420p、至多一条 AAC 音轨。动画、HDR、旋转及复杂流等保守跳过，不是全格式转换器。
- 普通、非加密 PDF 仅做结构与流重压，不栅格化、不降采样、不改变页面尺寸；加密/权限限制、签名、表单、脚本/动作、注释（含链接）、附件及复杂或损坏文件会跳过并解释原因。单 PDF 上限 64 MiB。
- 浏览器每批导入最多 200 个媒体、2 GiB；更大批次使用运行设备的目录扫描。单个图片/视频上限 1 GiB，导入区声明容量上限 8 GiB。目录扫描也受媒体自身安全限制。
- JPG/WebP/MP4 可能有损；不承诺固定节省比例。已优化素材或 PDF 可能无收益。未保留原件时，不提供虚假的前后对比。
- 当前不提供批量重命名、在线安装器、自更新、PWA、Chrome 扩展或手机客户端。Windows 使用 WebView2 独立窗口；网站代码引用不会自动改写。

### 数据与隐私

媒体处理在运行 MediaSlim X 的设备进行，不向第三方上传，无遥测、账号、广告或外部 CDN。本机浏览器入口导入文件时，所选媒体副本会进入本机服务。图片、视频和 PDF 也可能含敏感内容，请按自己的数据管理要求使用；其他连接方式的数据边界见[隐私与安全](privacy-security.md)。

扫描默认跳过隐藏、依赖、输出与备份目录，不跟随符号链接。处理保留指纹、结果验证与替换保护，但不承诺任意外部并发写入下绝对安全；首次使用和重要素材优先导出检查。

### 首次使用与升级

首次可用少量媒体跑一遍“扫描 → 默认导出 → 检查结果”。浏览器导入和目录扫描是两种入口：若希望备份后更新原路径，请选择运行设备的原目录；拖入的原件不会被自动覆盖。

当前没有自动更新；从真实 GitHub Release 人工检查、下载并核对新版本。升级前结束任务并安全关闭旧窗口/服务，把新版本完整解压到新目录，双击新 EXE。不要只替换 EXE 或混用旧 `_internal`。便携任务与导入数据位于 `%LOCALAPPDATA%\MediaSlimX\portable`，导出和备份仍在用户指定位置；删除程序解压目录不会清除这些数据。不承诺未验证的跨版本自动迁移，升级前保留重要报告和备份。详见[升级策略](updates.md)。

源码 `Start-MediaSlimX.vbs` 为无终端窗口入口；准备失败时用 `Start-MediaSlimX.cmd` 查看错误。`Start-MediaSlimX-Browser.cmd` 保留 Windows 本地网页入口；窗口与网页各自保存任务数据，不共用运行中的实例。
