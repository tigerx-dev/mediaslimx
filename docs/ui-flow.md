# 中文界面流程
## 布局
默认石墨深色工作台、薄荷色主操作，支持浅色切换和重载保持，系统字体，无外部资源。顶栏以 MediaSlim X 和“本地批量压缩工具”说明产品定位，并展示连接状态。主区标题表示当前上下文：准备目录、扫描和设置时为“新建任务”；任务创建后显示该任务的来源名称及实时状态，进度和结果各有自己的区块标题。标题下直接说明“图片、MP4 与符合条件的 PDF 在本机处理；默认导出，保留原件”，避免把 PDF 含混地称作多媒体。平台只在主区标签显示一次，页脚展示版本号；左侧工作区和历史任务；主区按阶段操作；窄屏垂直排列。
宽度至少 1001px 且可用视口高度至少 640px 时，应用框架适配 100dvh：应用栏、历史区和页脚保持定位；文件列表、参数内容和结果列表各自滚动。参数区底部的“开始优化”不随参数内容滚走。表头在对应列表内置顶。
扫描后缩短顶部介绍和目录区，把空间留给文件与设置；处理中优先显示进度、取消和逐文件状态，完整体积汇总在完成后显示。环境说明的标题与右端箭头保持一整行，宽屏展开后在下方显示两行概览；完整信息放在可滚动弹层，手机点击直接打开弹层。长路径与错误说明保留可滚动的阅读区域。
建议可用视口达到 1280×720px；这不是硬性最小尺寸。宽度或高度不足时切回自然页面滚动，顶部应用栏仍置顶，不以 min-height 把控件推出屏幕。这里的尺寸指浏览器内容区，不含工具栏；缩放后按实际 CSS 视口重新布局。
## 1 目录
显示运行平台、Python、FFmpeg 状态、CLI 授权根目录和范围说明。点击“选择目录”在授权范围内逐层浏览，包含允许根目录、上一级和子目录；浏览导航本身不扫描。确认媒体目录的按钮为“扫描此目录”，选定后立即进行只读扫描、关闭选择层，不再要求回主界面重复点“扫描目录”。手动粘贴绝对路径或需要重新检查时仍可用主界面的“扫描目录”；输出与备份目录选择仅填写路径，不发起媒体扫描。扫描不会开始优化，用户仍须明确点击“开始优化”。支持 Alt+O、Escape 和焦点返回。Windows --desktop 模式可使用系统窗口选择其他本机目录，真实选择后才加入授权并保存；不是文件上传器。系统选择待处理时显示状态和“取消系统选择”；点击取消、关闭面板或转回网页目录浏览会结束对应请求。旧返回不能填入重新打开的字段，失败后可重试。只显示系统目录选择器，不额外展示提示父窗口；缺少 Tcl/Tk 时提示可操作的替代方式。路径控件作为一个整体显示焦点边框；两操作按钮桌面等宽、窄屏等分下一行。初始状态“尚未扫描”，没有模拟数据。
发起扫描后禁用重复操作，显示“正在检查媒体”；失败保留原待处理列表并展示可操作错误。
## 2 扫描
数量、真实总大小、非媒体计数、隐藏文件与排除目录计数。列表展示相对路径、格式、大小、尺寸及支持原因，按大小默认排序；可勾选支持项，全选/清空。
不支持和损坏项保持可见，禁止勾选。空目录说明没有找到候选，提醒检查允许范围和排除目录；不承诺扫描已知节省量。
## 3 设置
宽屏文件列表与参数并排，窄屏纵排。三项画质预设。尺寸明确分为“仅压缩，保持原尺寸”（默认）和“压缩并等比缩小”；后者至少填一个最大宽高，两边同时填写表示边界框，不裁切、不拉伸、不放大。显示所选真实文件的尺寸示例。切回原尺寸后旧数值不提交。若结果未变小，仍按无收益规则保留原件及其原尺寸。提示 JPG/WebP/MP4 存在有损压缩，相同内容改变参数可重新压缩。
默认“导出至新目录”，填写输出根目录；备份覆盖填写备份根目录；直接覆盖出现必须确认的无备份提示。字段只在相应模式展示。
下拉控件为本地语义选择器：箭头有固定内距，支持列表高亮、方向键、Home/End、Enter/Escape；关闭后焦点返回。菜单独立于滚动面板显示，向上/向下适应可用空间；窗口尺寸变化或锚点随滚动移动时关闭，避免错位。键盘焦点导致的排队滚动事件不会误关刚打开的菜单。输出和备份输入旁也有选择按钮。
开始前展示原件如何处理、结果/备份目标预览和命名规则。保留原文件名、扩展名与相对目录；专属任务目录开始后在所选根目录下生成，名称由日期时间和短任务编号组成。旧任务保持原目录名。备份是复制原件再覆盖，不移动原件。开始按钮旁显示所选数量、尺寸策略和输出策略；无选择禁用。创建任务失败留在设置阶段并解释。
## 4 进度
任务创建后立即加入左侧历史列表并选中；主区标题、选中行和右侧进度始终指向同一任务。显示当前相对路径、已完成/总数、按完成文件数的进度条、累计实际节省与错误数。
取消剩余任务后按钮禁用并显示等待安全边界；当前文件可能完成，不回滚已完成结果。编码有超时，任务进度不是虚构的时间百分比。
## 5 结果
汇总状态、原/结果体积、实际节省与各状态数量。标题下的目录信息默认收起为“导出 · 保留原件”等模式及单行缩显的实际结果路径；点击“目录详情”行可展开并滚动查看来源、结果及用途说明，备份覆盖再列本次任务备份目录，直接覆盖说明无备份。任务切换时收起，不靠悬停自动遮住列表。导出结果使用本次任务专属目录；尚无结果时标记计划位置。Windows 独立窗口在来源仍可用、结果/备份已生成时于对应行显示次级文字“打开”，由后台按任务记录打开各目录；服务器网页只显示运行设备路径，不打开远端浏览器的文件管理器。逐文件筛选、路径/大小/节省排序，点击详情。
详情含相对路径、状态、原因、参数、耗时；图片可并排和放大，视频可前后分别播放，展示前后尺寸、时长、视频/音频编码。
前后预览根据原件是否实际可用；直接覆盖成功后仅有结果。原件/结果改变后拒绝预览并说明。
CSV 下载使用带令牌的 fetch 后本地生成下载链接，默认仅相对路径，防表格公式注入。
备份成功项可单项恢复或整批恢复；UI 弹出明确操作确认。冲突逐项显示，不提供“强制覆盖”。
历史任务来自 SQLite，完成后仍保留在左侧，重启可查；切换列表项时主区标题、状态和结果随选中任务更新。中断任务提示已完成结果保留。恢复后显示实际结果，原备份保留。
当前源码启动时核对异常前的进行中任务；提交边界核对后显示“已中断”，未完成项保留在清单，成功项留在结果明细。最近一条异常中断或安全暂停的任务会在主区打开，左侧“最近任务”也可重新查看；**不会自动开始处理**。繁忙窗口关闭时可“继续处理”或“保留进度并退出”；安全退出记录为“已暂停”。“新建任务 ＋”返回选择目录，不删除历史。结果页绿色提示明确显示可继续的剩余文件数量，并与结果内容共用左右内距；“继续剩余文件”只对尚未完成项运行，重新核对原件和已有备份；源变化、备份损坏、目标冲突等逐项报错，不覆盖新版本。冻结 r7 便携包仍是旧流程。

导出、备份覆盖、直接覆盖时源文件变化、导入副本已释放及真实 Windows 独立窗口续做均已用隔离合成素材验证；真实异常强杀后的恢复仍待专项验收。正常结束的任务无剩余项，不显示续做按钮。
## 全局状态
错误显示在页面可读区域并使用 aria-live；键盘可操作、焦点明显、支持窄屏。
令牌缺失时提示从启动终端打开完整 URL；授权失败不自动重试写操作。
页脚保留版本、免费开源说明与“导入副本空间”入口。没有真实链接时隐藏赞助入口及开发占位。

## 交互一致性
所有控件至少 44px 点击区域。主题仅改变语义色，不改变流程；减少动效设置去除位移，保留状态和焦点。异步读取使用意图版本，切换新任务后旧扫描/任务响应不能覆盖当前页面。取消写任务仍需明确点击取消。

## 细节规范
滚动条统一使用 --scroll-thumb / --scroll-track / --scroll-hover，列表、参数、历史、菜单与弹层随深浅主题切换。系统浏览器/OS 仍可决定滚动条是否自动隐藏。
主题按钮在深色时显示太阳（切换浅色），浅色时显示月亮（切换深色）；title 与 aria-label 同步，重载后与已保存主题一致。右上角只显示“已连接”，平台标签只出现一处；页脚为实际版本号。侧栏处理范围入口也打开运行详情弹层。

目录入口标题使用纯文字，文件夹标识只保留在路径框内，避免相邻位置重复同一图标。

## 列表固定与清理
- 最近任务第一行显示来源名称，第二行显示状态和上级路径；完整路径在悬停提示及 aria-label 中保留。进入可归档任务行时，单条归档与未固定图标同时出现，采用一致的轻图标样式；键盘聚焦任一操作也能显示，触屏常显。已固定图标常显；点击后直接可恢复归档，进行中任务不显示归档操作。
- 侧栏“整理”悬停展开或点击保持菜单，其中有“归档未固定 / 已归档 N”；键盘与触屏可通过点击使用。单条或整批归档成功后更新 N，不再常驻长提示。“归档未固定”确认框展示本次要移出的数量、固定项和进行中项的保留数量；取消不改变任何列表。确认使用当时明确列出的记录集合，服务端再次核对固定和状态，避免另一个页面新固定或新完成的任务被误清。
- 归档只将项目移出列表，原媒体、导出、备份、报告及 SQLite 任务记录都保留；“已归档”可查看原结果或恢复到列表。不是彻底删除，也不会腾空任务数据库。
- 目录弹窗左侧是“目录快捷入口”，与完整允许范围分开。快捷入口显示目录末段名称并单行缩显；已选目录在右侧显示完整路径，键盘和读屏也可取得完整路径。首次出现的启动根目录默认固定，其他入口可自行固定；归档只隐藏未固定入口，不删除文件夹、不增加或撤销授权。“已归档”可以浏览仍被允许的目录或恢复入口；完整允许范围仍在运行详情中。
- 两类固定及清理状态持久化，重启后保留。恢复到列表与备份恢复使用不同文案，不混淆操作。没有可清空项时按钮禁用，找回或清空后有焦点返回和状态提示。

## 拖拽导入流程
Windows独立窗口收到单个真实本机目录拖入时，先通过受限目录通道取得并校验该目录授权，再请求正常目录扫描；扫描成功后替换待处理列表、准备默认导出，原件保留。不先收集/上传200个副本，也不因数量超限要求重选同一目录；扫描不启动优化，仍需点击开始。扫描失败不丢原列表，旧副本不自动discard。隐藏/依赖、运行数据、输出与备份继续跳过，默认mediaslimx-export/backup等名称未登记时也排除。

原生拖入通道只针对一次拖入单个目录。散文件、多目录拖入、普通浏览器/远程连接的“导入文件夹副本”，以及导入列表的“添加文件夹副本”继续下面的副本导入流程；FileList不推导父目录，不绕过200项/2GiB。独立窗口空状态的“选择本机目录”另走受控系统选择器直接扫描。开始安全退出后拒绝新目录授权与扫描，不把目录通道作为网页可调用的任意路径接口。

空状态提供“选择图片 / 视频 / PDF”，页面可直接接收具体媒体文件。拖入时出现仅当前拖拽可见的边框提示，松开开始传输；不把合成数据填入列表。普通网页/远程连接可“导入文件夹副本”，任何导入列表可“添加文件夹副本”；递归按分批目录 API 读取至空批次，保留最外层与子目录，传输前过滤隐藏名称、依赖、已知输出/备份与非媒体，并展示跳过统计。独立窗口空状态的本机目录选择与单目录拖入使用上方直接扫描流程。

入口持续显示“每批最多200项/2GiB”及大批量改用运行设备目录扫描的提示。超限时展示结构化面板：文件数量、目录项与层级对照已发现值和对应上限，批容量仅明确2GiB上限，不展示精确已发现字节。面板明确本次新增传入0项，不上传部分列表、不截取前200项。已有待处理列表、勾选、输出位置和模式保持；主操作指向运行设备目录扫描，次操作关闭提示并返回现有列表。

目录面板在此流程中明确显示“扫描此目录”及“系统选择并扫描”，并说明只扫描、仍需点击开始优化。取消选择、关闭面板或扫描失败均保留旧导入；只有扫描成功才替换来源与列表，并采用默认导出。成功切换也不自动丢弃旧导入副本，可稍后在独立空间管理中主动释放。服务器实例选择服务器上的目录，不根据拖入名称定位本机绝对路径。

媒体区切为紧凑“文件导入”条，显示实际完整文件数量/大小以及添加、清空入口；“添加文件夹副本”仍追加到当前导入列表，浏览器可能给出自己的传输确认。回目录扫描放在限额提示行，以默认虚线下划线、悬停实线下划线的文字链接样式呈现，点击打开目录面板，不委托给清空导入，取消不discard副本。网页/远程空状态的“扫描运行设备目录”采用同样样式；两处保持按钮语义、44px热区与键盘焦点。传输期间显示当前文件、真实字节进度与“取消剩余导入”；锁定开始优化与切换来源，避免误提交旧列表。传完复用待处理表，实际格式校验决定可选项；重名、损坏、不支持、未完成传输都有原因。追加保留原有勾选。

空状态的三条处理原则置于两个主入口之上。Windows 独立窗口把“导入文件夹”改为“选择本机目录”：直接呼出系统目录选择器；成功后授权并扫描本机目录、准备默认导出，系统窗口取消或页面“取消系统选择”均保留当前列表和设置，扫描后仍须点击开始。页面取消复用既有原生选择取消端点，选定结果若迟到也不发起扫描。该路径不走浏览器文件夹输入，因此不会触发浏览器的“上传到此站点”确认；同一空状态隐藏重复的目录扫描文字链，已授权目录仍可从上方路径区选择。普通网页/远程连接的第二主入口明确叫“导入文件夹副本”，从浏览器所在设备复制到当前服务，保留200项/2GiB限制及浏览器可能给出的原生确认；旁边“扫描运行设备目录”只查服务设备路径，二者的访问范围不能混称。单个真实目录拖入独立窗口的原有直接扫描继续保留。

短桌面窗口让主区滚动，待处理工作区保留360px可用高度，说明和操作都可滚至，不靠缩小字号或裁掉底部按钮适配；中英长文、面板内容和helper提示行保持自然换行。

导入模式固定导出，明确“不能覆盖拖入原件”，说明副本存于当前服务。输出路径属于当前服务平台，首次导入使用独立默认目录。完成后增加“下载导出包”，提供实际结果与 CSV；详情里的前图明确称“导入原始副本”。历史行展示“文件导入 · N 项”，实际内部路径仍能在位置详情中查看。

未使用导入可清空返回目录。刷新遗留的未使用副本以空页面次级“清理未使用副本”文字入口呈现，确认说明实际删除副本、原件/任务原始副本/结果保留。任务列表清空仍只隐藏记录。

固定图标采用更小的 14px 线条，无常驻底色或边框；未固定倾斜 35°，固定竖直、填充且轻量强调色，保持 44px 可点区域和 aria-pressed，减少视觉体积并保留触控可用性。

## 中英文切换
默认中文，顶部 EN / 中文切换并以 localStorage 保存。界面原文和本地英文词典分离，显示层保留原文绑定，可翻译静态/动态文本、原生确认文案及 aria-label/title/placeholder；不刷新、不重建任务或重新选择源，不改变文件名、路径、输入值、媒体元信息或 CSV。目录下拉从原始文案建立，防止先以英文启动后切回中文仍残留英文。系统窗口由操作系统提供，其诊断与原始媒体元信息可保留原语言。

## Windows独立窗口退出

空闲点击窗口标题栏X直接退出；工作繁忙时在同一工作台显示当前主题、当前语言的退出层，不同时堆放中英两套文案。默认焦点为“继续使用”，点击继续、右上角叉号或Escape均保留任务并返回之前的有效控件，避免把焦点送到skip-link。选择“安全退出”后只提交一次，禁用重复按钮并显示收尾状态，等待自己的媒体事务、助手与服务结束；已完成结果、记录、报告和备份保留。

仅独立窗口的页脚显示低频“退出工具”，通过原生窗口的同一关闭流程处理；浏览器和服务器不显示。重复请求复用单层与当前nonce，不叠弹窗。页面未能在3秒内确认显示时，host撤销旧nonce，改用当前语言、默认“否”的系统确认；没有超时自动退出。语言/主题偏好只调整显示，不授予目录或关闭权限。

## 可读性与备份快捷流程
现行字号、对齐和响应式规则以根目录 DESIGN.md 为准，中英文文字最小 12px。侧栏清理文字与标题/任务名共用左右内距，命中范围至少 44px；英文长按钮允许换行。手机连接文案以有可访问名称和 title 的状态点呈现，释放主题/语言按钮空间；完整连接文案仍提供给辅助工具。

目录设置的“备份原件，再原位优化”复选框与处理方式双向同步；勾选显示备份位置，取消勾选回到导出。新任务重置为导出，不将上次的覆盖模式悄悄带入新任务。

导入设置仍锁定导出，并提供“选择原目录，备份后优化”。打开目录面板期间不改变当前导入；只有选中目录并扫描成功后才退出导入、替换列表并准备备份模式，取消或失败保留原列表/勾选/输出/模式。这个用户主动请求的备份流程保留，不与超限后的默认导出扫描混淆。当前服务的允许范围和Windows系统选择授权规则继续生效，不能根据浏览器文件名猜测原路径。扫描结束仍需明确点击开始。

超过浏览器导入数量/容量/枚举限制，使用上方结构化说明与扫描入口，扫描成功后才进入默认导出；失败发生于新文件分配/上传之前。单PDF超过64MiB时说明超过64MiB，不承诺显示具体大小，也不混同200项数量限制；改用目录扫描并不会使超范围PDF变为支持。目录选择弹窗以可滚动中区保持确认与关闭按钮可达。

## 空状态操作分组
“选择图片 / 视频”“导入文件夹”保持同一行并按可用宽度换行；“清理未使用副本 · 数量”居中放在下方独立次级行，不与导入入口混排。没有未使用副本时整行不占位。清理仍需确认，取消保留副本；确认只清理当前服务保存且未被任务引用的副本，保留源媒体与任务原始副本。

空态内容在矮窗口需要内部滚动时采用安全居中，首行说明与末尾按钮都可到达，不能因垂直居中让上半内容落到无法滚回的位置。

## 类型勾选、稳定披露与动效
扫描与导入后的同一选择工具栏包含“全选”“清空选择”和“按类型选择”。选某类型会替换当前勾选，仅选已检查且可处理的对应真实格式，JPG 包含 .jpeg。没有可处理项的类型在菜单中禁用；方向键/Home/End 跳过禁用项，Escape 返回触发器。手动改变勾选后仍能继续操作；混合/部分选择回到“按类型选择”提示，完整选中某类型时显示对应类型。列表不被过滤，开始仍需明确点击。

表头“选择”与每行勾选框使用同一 64px 列中心线。勾选轻量改变行底色与控件颜色；已选数量通过 aria-live 礼貌更新。实际任务只提交选中的可处理文件 ID；结果页仍可展示扫描发现的损坏/不支持检查记录，这些记录没有执行优化。

宽屏环境说明展开不再重排标题列，右端箭头原地旋转；同一坐标可再次点击收起，Space/Enter 保留原生 details 操作。展开/收起分别以 220/180ms 测量高度过渡，快速反向从当前高度继续；收起内容 inert，内部焦点回到 summary。响应式、语言变化与减少动态效果会结束旧动画并保留最新状态。工作区首屏与实际步骤变化作轻淡入；同一步骤轮询、逐项勾选、追加和语言切换不重复播放。新步骤可取消未完成动画，减少动态效果时取消动效并保留全部操作。


## 开始前的处理计划
开始按钮上方的单行摘要可点击打开宽的只读处理计划。摘要显示文件数、画质、尺寸与输出方式，过窄时截短；参数滚动时仍可点击核对完整内容。“优化参数”标题旁的“展开设置”文字按钮放大原有参数表单为覆盖层，列表原地不动，设置不会重置；收起按钮用向内四角图标，区别于关闭弹窗的叉号。展开层从右侧短距离滑入，点收起、点面板外遮罩或按 Escape 时向右短距离退回并完全淡出，然后恢复窄栏、背景操作与入口焦点，避免退场末端看似回弹；若进入其他任务步骤则立即结束覆盖层。遮罩同步淡入淡出，不推走列表；减少动态效果时直接显示最终状态。标题区不再放第二个“处理计划”入口。展开层保留可滚动的配置和固定开始按钮，窄屏同样使用覆盖层。没有 hover 自动弹出或鼠标移入就遮挡列表的行为。超宽桌面增加主内容宽度，右栏约360px，文件列表使用余下空间；普通桌面保持现有布局。路径输入焦点仅显示一条连续高亮边界。计划面板桌面双列、手机单列，固定标题与返回按钮，中间滚动；查看、返回、Escape 均不创建任务。

展示真实勾选数量与总体积、格式、画质预设、尺寸上限及首个所选文件的尺寸示例；说明有损边界，不估算准确收益。文件去向按三种模式展示源/副本、结果、备份路径，任务目录仅用明确占位。浏览器导入展示当前服务副本，说明无法获得原件绝对路径，不能伪造源路径。

命名区明确保留原文件名、扩展名与目录，使用选中文件展示“原相对路径 → 同名相对路径”，不修改网站引用；导入重名编号规则保持。当前不实现批量重命名。后续产品方向为导出模式的主动选项，支持未发布素材场景；须先落实命名规则、示例与重名冲突保护，不将其混入覆盖/恢复流程。


## 全宽计划与归档外框
处理计划改为全宽信息分区，区块标题与正文列对齐；长路径、命名、无收益与恢复说明使用完整正文宽度。650px以下单列，标题/返回固定、中间独立滚动；真实文件名只显示一次，不重复长名箭头。任务选中框包含固定按钮；归档条目外框包含查看与恢复按钮，手机恢复按钮在同框下一行。

任务和目录入口使用“归档未固定 / 已归档”，确认说明只收起列表，不删除数据、不自动过期；归档列表可查看或恢复。恢复最后一条时自动关闭已归档层，焦点回到可用入口；还有其他条目时留在列表继续操作。恢复只移回主列表，不执行媒体恢复；任务详情的备份恢复保持独立行为。

PDF加入拖入/文件夹/扫描与类型选择。列表显示真实PDF页数，不出现undefined×undefined；全PDF时禁用画质/尺寸并解释，混合时这些设置只作用图片视频。计划显示PDF压缩边界。含PDF时禁用无备份覆盖选项；若之前已选该模式，禁止开始直到主动改选导出或备份。详情仅下载，不嵌入；加密等逐文件说明不支持原因。缺少pikepdf时环境详情和候选条目均提供当前平台安装命令。


## 表格基线与选择热区

## 删除归档任务记录
归档条目内“删除记录”与查看、恢复共用外框；只对task提供，目录快捷入口没有危险删除记录功能。点击先取服务端影响快照，再打开独立确认层；下层归档仍在，取消/Escape回原入口。确认层显示具体任务、关联数量、失去工具内CSV导出/预览/恢复入口、保留所有文件与已保存报告；有备份说明手动定位恢复，无备份明确未记录备份。主动勾选理解后按钮才启用，提交中禁止重复。

成功从归档移除该条，主列表计数刷新；若下层正展示该任务结果则清空，关闭确认后焦点到归档关闭按钮。失败在确认层可见，撤回勾选；状态变化须重新查看后确认。网络丢失可重试同一已确认版本，服务端幂等处理。取消不删；文件清理不由该操作触发。标题/底部按钮固定、中区滚动，中文≥12px，手机不遮挡风险说明。

归档本身仍只收起列表，确认辅助短句采用“仅收起列表；任务、报告和备份保留，可随时恢复。”。桌面尽量一行，手机允许自然换行；自动过期政策保留在归档列表说明，不重复长句挤占确认层。


## 导入副本空间

页脚入口不依赖空页面。面板列出实际占用/预留配额和逐批状态，刷新可重试错误；批次操作与内容共享外框。释放前独立确认层显示影响，主动勾选后才能提交。取消/Escape返回原入口，长说明中间滚动，关闭和底部操作可达。校验/提交期间有真实状态，拒绝原因就地展示；失败后需重新查看，不能沿用旧确认。

8GiB实例导入配额不足时单独展示空间说明和“导入副本空间”入口，不将其当作每批200项/2GiB限制，也不自动清理或扩大配额。进入空间管理只查看占用；实际释放仍需原有影响预览与主动确认。关闭配额提示或取消清理均保留现有导入及任务。

成功更新配额与批次状态；释放当前未使用批次会清掉待处理列表，已完成任务保留结果。详情不请求已清理前图，说明原件对比不可用；CSV、结果预览和ZIP继续可用。完整规则见 [storage-management.md](storage-management.md)。

## 文件详情的阅读顺序
标题只保留相对路径和右上角叉号，叉号44px热区与关闭详情的可访问名称保持；文件路径最多三行、可聚焦滚动。标题固定，.detail-content中间独立滚动，手机不需要滚回顶部才能关闭。关闭或Escape暂停视频并把焦点还给打开详情的按钮，轮询换节点时回同文件新按钮。

先读状态/原因和原大小、结果大小、实际节省、耗时，再看原件/结果预览。可读元信息与所属预览共用一张卡：图片格式/尺寸/色彩；视频时长/编码/帧率/像素/音轨声道；PDF页数与版本并维持下载。桌面预览并排、手机上下。没有原件只放真实结果并说明不能对比，没有可用结果明确提示。

处理参数默认可读标签/值，质量数值、预设、编码器、尺寸及音轨等按实际记录呈现。无收益说明尝试未采用；重复跳过未再次编码；恢复后当前元信息/字节是原件，原输出尺寸等留作原处理参数。缺少实际参数只展示任务设置。原始JSON不再默认铺开，收进“技术详情”（原始元信息/处理记录/任务设置），可展开核查。


图片点击后在页面内打开独立放大层，不新开浏览器窗口；网页和 Windows 独立窗口使用同一流程。标题和44px叉号固定，中间图片区域独立滚动；提供适应窗口、100%原始尺寸与10%–400%分级缩放，保持图片比例，图片小于窗口时不默认放大。原始尺寸或放大后使用滚动查看；键盘 + / − 缩放、0 适应、1 原始尺寸，聚焦图片区域可用方向键滚动。缩放不修改文件，不切换原件/结果：查看哪张预览就放大哪张。

放大层的叉号/Escape只关闭当前层，回到原预览按钮，底下详情保持；详情关闭时一并结束放大层。只使用既有认证预览地址，仍检查文件指纹与允许范围；加载失败就地说明，不外跳、不嵌入 PDF，不创建额外文件。减少动态效果沿用现有弹窗规则。
