# 界面语言维护

空间管理与释放确认的指标、影响、按钮、后台保护原因、已释放详情说明均同步本地中英词典。批次 ID、文件名和路径保持原文，日期按界面语言显示；校验或提交期间不重建确认状态。长英文使用完整正文宽度和中区滚动，不缩字。没有真实链接时，中英文均不展示赞助占位。

## 范围
默认简体中文；顶部 EN / 中文即时切换，localStorage 键 mediaslimx-language 只保存本机偏好，不联网。界面为中文和英文两种，不使用系统语言自动覆盖用户选择。

覆盖静态页面、动态摘要/进度/结果/恢复状态、目录与清理弹层、应用可解释错误、title/aria-label/placeholder 和应用确认文案。原始文件名、路径、媒体元信息、任务记录和 CSV 不翻译；CSV 原因保留记录原文。操作系统错误和原生文件夹窗口的标题/控件可能保留本机或固定语言，不能把界面切换称为系统语言切换。

## 文件
- static/i18n-catalog.js：中文原文到英文的固定词典，随工具分发。
- static/i18n.js：动态模板、原文绑定、语言选择和 DOM 显示更新。
- static/index.html：中文原始界面与语言入口。
- static/app.js：业务仍使用稳定 API 枚举与数据；原生确认使用 t()；下拉从 sourceText() 读取原文。
- README.md / README.en.md：中文/英文安装、使用与边界说明。

没有前端构建、外部翻译 API、运行时 AI 或新 Python 依赖。

## 原文绑定与数据保护
显示层以 WeakMap 保存文本/属性的原文和最近显示值，切换时从原文重新显示；MutationObserver 只处理新增文本、文本变化和指定可访问属性。自身更新与业务更新分开识别，避免循环或重复翻译。不使用 innerHTML，不重建任务、不刷新页面，也不写入源媒体或数据库。

用户内容和真实路径节点使用 data-i18n-skip，避免名为“成功”或“原文件”的目录被翻译。输入 value、name、ID、API 参数、数据属性及状态枚举不进入翻译。媒体 JSON、pre/code 保留原文。动态模板中的文件路径原样插入，不能通过替换中文片段改文件名。

下拉选项在保存语言为英文时启动，也必须从原始文案生成，确保切回中文能恢复；不能直接把已经显示的英文再次当作中文原文。时间格式按界面语言生成，切换只刷新历史的读取展示，不触发文件操作。

## 添加文案
1. 固定文案在词典中提供准确英文；新动态数量、路径和错误前缀在 i18n.js 添加受控模板。
2. 不对文件路径做随意全局子串替换，不翻译媒体元信息。
3. 新的用户原始内容节点加 data-i18n-skip；不要把整块有界面文案的结果面板一并跳过。
4. 确认中文默认、英文切换、以英文偏好重载后再切回中文都可用。
5. 语言不影响业务状态。导入、取消、恢复中的 API 与原状态检查保持稳定。

## 验收
tests/folder-language-browser.cjs 在独立服务和真实合成目录上验证：
- 保留扫描 ID、勾选与输出值，切换不刷新。
- 英文设置和结果视图无残留的应用中文文案，原文件名与相对目录仍是原文。
- 英文持久重载、下拉恢复中文、可解释错误、对比预览。
- 320/390/768/1001/1440px、44px 目标、640/720/900px 高度的主操作。
- 传输中切换语言仍可取消，清理期间阻止新来源操作。
- 浏览器网络请求全部留在当前 MediaSlim X 服务。

测试不声称覆盖每一种系统错误语言或所有浏览器；Chrome 在 Windows 与 WSL 分别实测，具体结果见 development-plan.md。

## 排版约定
- 中文和英文共用断点和组件；短标题/提示平衡换行，说明使用 pretty 回退，不对整段中文强制不换行。
- 不在业务文案里插入只适合某个宽度的硬换行；路径/文件名保持原文并允许必要的任意位置换行。
- 新增或修改英文后检查完整按钮文字和弹窗，不只检查 document 是否溢出；选项允许多行，交互区域仍至少 44px。
- 文件表格允许独立横向滚动；手机不将文件大小或状态挤成单字列。
- tests/bilingual-layout.cjs 在隔离服务上检查两种语言、320px 至 1440px、横屏短窗口、实际扫描导出和长路径展示。MSX_PLAYWRIGHT、MSX_CHROME、MSX_PYTHON 的平台用法与 folder-language-browser 相同。

中英文共用 DESIGN.md 的字号变量与 12px 下限。备份勾选、导入转目录与导入超限引导均有本地英文词条，切换不改处理模式、路径或待处理选择。手机窄屏连接状态的可访问名称和 title 随语言切换。

未使用副本的数量标签使用明确模板翻译，避免先匹配通用“文字 + 数字”模板后丢失分隔符附近的译文。验证需包含真实存在未使用副本的状态，不能仅看新数据库中隐藏的清理按钮。

类型选择复用原有 select/listbox：显示文字由词典维护，JPEG/PNG/WEBP/MP4 的 option value 与后端格式枚举不翻译。先以英文偏好重载后仍可切回中文；动态勾选只更新展示，不改变媒体格式或路径。禁用项同步到真实按钮与 aria-disabled，键盘跳过。


处理计划包含静态词条与动态尺寸模板（最大宽/高），使用当前预设与选择实时刷新；相对文件名示例明确 data-i18n-skip，原路径不改写。计划内使用 14px 正文，12px 下限，英文长句在面板正文换行、独立滚动，不能用缩字解决。语言变化时已打开的披露动画落到最新状态，不重播工作区。


归档替代原“清空”任务/目录入口文案，原持久API与旧文本翻译兼容；动态“已归档N条/归档这N条”均使用数量模板。PDF模块新增状态、页数、保存限制、下载与不支持原因双语词条；加密文案明确不解密或移除访问限制。文件名与原路径保持原文。计划分区不再中英左右对半，长英文在完整正文列换行。


删除记录确认层的标题、风险/无备份/有备份分支、计数标签、确认勾选、按钮与后端拒绝原因均使用本地词典。任务路径和时间上下文保留原文，不参与翻译；确认层英文长文通过可滚动正文处理，字号不缩小。归档短句单独维护中英词条，桌面一行验证不强制手机nowrap。


文件详情新增可读元信息/参数/状态说明，使用本地中英词条；文件名、格式/编码/像素/数值等记录值保留原文。技术详情内JSON位于pre中，不参与翻译。无收益/重复/恢复/失败分别使用准确标题和说明，不能以翻译改变是否已采用处理结果。叉号无可见文字，title与aria-label继续随语言切换。
