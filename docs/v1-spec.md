# 第一版规范
## 产品边界
MediaSlim X 是本机/服务器媒体优化工具。仅在用户通过 CLI 明确允许的根目录内扫描用户指定目录。
UI 采用选择目录 → 扫描勾选 → 设置 → 处理进度 → 结果与恢复的流程。
核心功能免费，单进程、单个写任务；SQLite 持久化，无队列基础设施。重启核对提交边界，将未完成任务标为中断，保留已完成项和备份；展示最近中断或安全暂停任务，但不自动续跑。用户点击“继续剩余文件”后，按原任务逐项复核源指纹、备份及目标，已完成项不重新编码；源变更或冲突逐文件失败。旧 r7 便携包没有此入口，仍需用当前源码或后续新候选。
## 媒体支持
- JPG/JPEG、PNG、静态 WebP；验证内容与扩展名一致、能完整解码，图片不超过 5000 万像素。
- 动图、多页图片、16 位/特殊色彩模式、含 EXIF 旋转的图片保守跳过并说明；不悄悄旋转改变含义。
- 普通 MP4 限制：恰好一条 H.264 8 位 yuv420p 视频流，零或一条 AAC 音轨，无字幕、附件、数据或其他流；无旋转、HDR、透明通道、章节或加密；时长、尺寸、帧率有效。
- 对未知色彩信息仅接受普通 8 位 SDR 编码，显式 BT.2020/PQ/HLG、HDR side data 等拒绝。没有 ffprobe/FFmpeg 时 MP4 不支持且展示安装说明。
- GIF、AVIF、HEIC、MOV、MKV 等媒体候选列为不支持；非媒体仅计数，不打开内容。
- 可选普通 PDF：安装 requirements-pdf.txt 后支持非加密静态文档的结构/流重压，页面尺寸和图像质量不变；64MiB以内、无复杂内容，具体边界见下文。PDF仅允许导出或备份覆盖。
## 默认行为
均衡预设，原尺寸，导出新目录；不自动转换格式，不改网站代码。图片质量（JPG/WebP）画质优先 90/90、均衡 82/82、体积优先 70/70；PNG 为无损编码优化，主动缩小尺寸才改变像素。
MP4 使用 libx264，CRF 20/23/28、medium、yuv420p、faststart，AAC 音轨直接复制；无音轨不新增。尽力保留 ICC、EXIF、PNG 文本、WebP XMP 和常见视频元信息，不保证私有扩展块完整保留；不做自动隐私擦除。
最大宽高可分别设置，保持比例且不放大。因 MP4 需要偶数尺寸，奇数尺寸 MP4 跳过。
无收益指新文件大小不小于原文件：原位保持不动，导出复制原件，不能计为压缩成功。
## 输出、备份及恢复
导出根目录/task-id/相对路径；备份根目录/task-id/相对路径，按任务隔离，拒绝覆盖已有文件。
输出/备份根目录不能等于或包含扫描根目录；允许位于扫描树内，但被当前和后续扫描排除。运行数据目录同样排除。任务记录永久保留这些排除范围。
三种模式：export、backup、overwrite。直接覆盖需 UI 明确勾选无备份确认，API 也校验确认字段。
先将媒体打开到私有快照，校验扫描指纹；在目标同文件系统创建临时文件，完整处理和解码验证，再次核对源文件指纹后原子替换。
SHA-256、大小、纳秒修改时间、实际参数、耗时和输出指纹保存。相同已处理内容及相同参数拒绝再次有损处理；参数改变允许主动重压并在 UI 提示。
恢复只适用于确实写入了备份的成功文件：核对压缩后指纹，冲突、丢失、备份损坏时跳过，不强制覆盖。
取消为协作取消：当前文件到安全边界，未开始项标取消，已完成项保留，临时文件清理。
## 异常与统计
列表状态包含成功、无收益、重复跳过、不支持、损坏/失败、取消、恢复成功、恢复冲突。扫描不预估准确节省量。
汇总原大小为该任务全部条目的扫描大小；结果大小以已完成输出为准，其余用原大小计入，并明确失败/取消项没有结果。恢复后重新计算当前结果大小。
扫描无访问权限、文件改变、磁盘不足、编码超时或依赖缺失，都明确报错，不伪装成功。单文件失败不阻止其他文件。
## 验收标准
- 合成 JPG/PNG/WebP/MP4 从扫描到导出、预览、CSV 和重启历史完整可用。
- 边界穿越、符号链接、隐藏及依赖目录不处理；API 不接受任意预览路径。
- 三种模式、恢复冲突、源改变、重复压缩、损坏、无收益和取消均有实际风险测试。
- Origin/Host 与访问令牌校验拦截其他站点读写。
- 测试结果记录开发计划，不为 FIRANO 编造数据；平台实测状态见 platforms.md。

## Windows窗口生命周期

Windows独立窗口空闲关闭直接退出，繁忙关闭优先使用当前主题、单语言HTML确认层，默认继续；Escape、叉号和继续均保持工作，只有安全退出提交一次取消与安全排空。页脚退出入口只在窗口模式出现，走同一原生OnClosing协调器，不增加HTTP关闭接口。已完成结果/任务/报告/备份保留，仅结束本实例拥有的服务与助手。

host创建一次性nonce并等待页面确认显示；固定字段、所属顶层来源、pending与nonce匹配均验证。错误/旧nonce或无pending的退出回应无效，语言/主题消息不授权关闭或媒体范围。3秒未确认显示才撤销nonce并进入单语言默认No的原生确认，不因超时自动退出；界面撤销后恢复按钮可用与合理焦点。平台报告区分真实窗口DOM/协议、人工物理点击和干净Windows。

## v0.2 本地运行补充
Windows 双击脚本与 WSL 启动脚本分别定位自身目录，分离解释器、数据目录、端口和预览 Cookie；就绪后自动打开网页，已有服务复用。新增受限目录浏览和 Windows 显式 --desktop 系统选择入口。默认深色/可选浅色桌面工作台，支持键盘下拉、焦点与减少动效。实际平台状态以 platforms.md 和 development-plan.md 为准。

## 尺寸与目标引导补充
默认仅压缩并保持原尺寸；主动切到等比缩小时至少填写一个上限。两个上限是容纳边界，不代表输出必须等于这对宽高；只缩小，不裁切、不拉伸、不放大，像素按整数取整，视频按编码要求对齐偶数。未变小仍执行无收益保留原件策略，因此本工具不保证强制输出指定尺寸。
开始前显示输出/备份关系与路径预览，任务目录为待生成占位；结果页以简短模式标识说明导出或原位处理，再分行解释来源、结果与按需出现的备份目录，并显示真实路径。Windows 独立窗口对可用目录提供按任务记录推导的次级“打开”操作；服务器网页只展示路径。命名保持原文件名、扩展名、相对结构。导出和备份在所选根目录下按日期时间及短任务编号建立独立任务目录，避免覆盖旧任务；旧记录沿用原完整编号目录，不迁移或改写。备份是复制原件后再替换源路径，非移动原件。

## 任务和目录列表整理
固定项默认不随清空移除，任务进行中/取消中/恢复中也保留。清空未固定项必须确认，确认只涵盖当时展示的集合，提交时重新检查固定和任务状态。清空采用隐藏标记，保留原任务、报告、去重指纹、媒体与备份，可找回；不等于彻底删除数据。
目录弹窗展示的是授权根目录的快捷入口，隐藏和固定只改变展示，不增加或撤销授权。启动根目录首次出现时默认固定，可主动取消固定。“已清空”可找回仍被允许的入口；完整允许范围独立展示。

## 文件导入补充
Windows独立窗口的单个真实本机目录拖入采用目录扫描，而非副本导入：仅从WebView2提供的真实目录对象取得路径，原生host与Python所属实例双重校验、授权后请求正常扫描，默认export。空状态“选择本机目录”也直接通过既有受控系统目录选择器选目录并扫描，不使用浏览器文件夹上传输入或其原生上传确认。扫描不优化或覆盖，仍需开始；取消/失败保留原列表，旧导入副本不自动删除。单个目录拖入通道仍只针对真实目录对象，不从子file推导parent；当前导入列表的“添加文件夹副本”、散文件、多目录、普通浏览器和远程连接继续副本导入及200项/2GiB限制。

目录窄通道仅接受所属工作台顶层页面的固定操作和真实WebView2目录对象，不接受JSON传任意路径；不提供公开HTTP授权或关闭接口，closing后拒绝。默认mediaslimx-export/backup及复数形式即使尚未登记也列入目录排除，隐藏/依赖/运行数据/已登记输出备份、no-follow与Windows重解析点保护保持。目录扫描不绕过媒体支持边界。

其余副本导入入口为拖入具体文件/多个文件夹，或普通浏览器与文件/文件夹选择按钮；递归保留相对结构，不试探原始绝对路径。浏览器显式传输所选字节到当前实例，副本导入不授权原目录；正常扫描只遍历已授权范围。候选JPG/JPEG、PNG、WebP、MP4与可选普通PDF复用真实格式检查；损坏或不满足支持条件者显示失败/跳过。

导入列表支持追加、稳定条目标识和大小写无关的重名区分。文件名采用跨平台规则，拒绝目录分隔、ADS、控制字符、Windows 保留名、隐藏名及结尾点/空格；物理接收路径由服务端生成，与客户端名称分离。文件数 200、单文件 1 GiB、单批 2 GiB、平台总声明容量 8 GiB，并检查磁盘空间；不是收益或画质承诺。

空状态持续展示200项/2GiB限制，提示大批量可扫描运行设备上的目录。数量、目录项与层级超限使用已发现值/上限的结构化对照；批容量只说明2GiB上限，不报告精确已发现字节。明确本次新增传入为0，不分配/上传部分列表，不截取前200项；已有导入、勾选、输出位置和模式保持。单PDF仍以64MiB为上限，超过时说明超过64MiB，不承诺面板展示其具体大小。

超限主入口打开运行设备目录面板，明确“扫描此目录”和“系统选择并扫描”，只扫描不启动压缩。取消或扫描失败不改变原导入状态；扫描成功才提交来源/列表转换，并将该超限引导的处理模式设为默认export。现有主动“选择原目录，备份后优化”入口仍在扫描成功后准备backup，不能被默认export引导覆盖。转目录成功后也不自动discard原导入副本；按独立手动空间管理保留和释放。目录扫描不绕过媒体格式、PDF大小及目录授权边界。

JSON 声明后逐文件 PUT 二进制流，实际大小必须与声明一致；临时文件独占创建，写完、fsync 并原子提交才标记完整。中断清理 `.part` 并释放锁，启动也清理已知未完成临时文件。完整文件先验证再加入待处理列表；取消保留已完整传入部分。已上传字节不能被相同上传请求覆盖。

导入任务强制 export，客户端改写覆盖参数也拒绝；导入快照更新后旧扫描失效，创建任务与锁定导入记录在同一事务中，防止扫描后追加或重复提交。默认保留原始副本，重启后历史、预览与下载仍有效；用户通过独立空间管理显式释放后，原件预览与再次处理不可用，保留任务记录、CSV、结果预览和 ZIP。下载 ZIP 只包含实际生成且指纹通过的结果及相对路径 CSV，不加入服务任意文件。结果修改后拒绝打包，不以旧指纹宣称成功。

未用于任务的副本可以清理；批量清理只处理确认时的 ID 集合，提交时重新检查传输/验证活动及任务引用，已有任务即使被隐藏也受保护。此清理会实际删除导入副本，与仅隐藏任务列表的“清空未固定”不同，界面明确说明，不触及浏览器原文件或导出结果。

## 导入副本空间与释放

默认保留历史导入副本；独立空间管理允许用户显式释放，规则见 [storage-management.md](storage-management.md)。列出真实占用、声明预留配额、可用配额、文件示例与任务关联。释放前服务器生成完整文件/目录快照和版本，主动确认后重验；上传/处理/恢复、链接、未登记文件和校验异常禁止清理。不递归删除，不删除拖入原件、结果、备份、任务、CSV或处理指纹。

成功保留清理状态并释放配额；原件预览和旧扫描处理被拒绝，结果预览、报告和ZIP仍检查指纹并可用。部分失败保留剩余副本与配额，重启不自动续删，必须重新预览确认。已删任务的sealed副本只能走此明确流程，不进入旧unused快捷清理。

8GiB总声明配额不足使用独立空间说明和存储管理入口，不与单批上限混淆，不静默释放副本或调整后端限额。打开管理面板不执行清理；释放继续要求原有影响预览、版本校验和主动确认。

## 文件夹路径与双语补充
文件夹导入保留最外层目录名，服务端随机平铺的收件副本不随客户端路径写入。相对路径单独校验：拒绝绝对路径、反斜杠、空段、点段、保留名与隐藏段；最多 20 层目录、1024 UTF-8 字节。目录大小写统一到首次导入的写法，兼容 Windows；已有文件占用新目录前缀时拒绝，新增文件与已有文件/目录同名时编号，不同目录同名保持。ZIP 沿用经校验相对路径，顶层 report.csv 目录保留给报告名，发生冲突明确拒绝。旧的平铺导入记录无需迁移，仍可处理及预览。

目录规则由 /api/imports/policy 从扫描规则与实例登记输出/备份名称提供，拖拽递归在枚举前过滤目录、请求 File 对象前过滤非媒体，文件夹 FileList 选择在读取/传输前过滤名称，服务端分配阶段再次拒绝排除路径。浏览器不提供原始绝对路径和完整原生属性，因此按名称保守匹配；操作系统隐藏属性/链接的严格边界由直接目录扫描完成，浏览器差异须据实标注。默认仍只导出，不移动/覆盖原件。

界面提供中文和英文，默认中文，本地记住语言，无外部翻译请求。切换保留选择、设置、传输与任务状态；任务 ID、API 枚举、数据库原记录、指纹、原始路径及文件名不随语言变化。英文说明为 README.en.md，中文说明仍为 README.md。

## 界面补充：备份快捷选项与字号
目录扫描可主动勾选“备份原件，再原位优化”，映射既有 backup 模式，不新增媒体写入路径。默认与新任务均为 export；取消勾选也回到 export。直接覆盖仍需明确选择与确认。

浏览器导入只导出。原位处理入口要求重新选择运行设备上的真实目录，取消选择或扫描失败保留现有导入；扫描成功后才切换列表并准备备份位置，再由开始操作触发写入。导入200文件/2GiB上限继续生效，超限不上传部分列表；可改用默认导出的目录扫描引导。源码变更不自动更新正在运行的旧便携实例。

所有中英文字遵循 DESIGN.md 的 12px 下限与字号层级。验收包含实际计算字号，不只检查页面宽度。

按媒体类型选择只改变 selected ID 集合，不修改扫描内容、媒体参数、文件或输出模式。归类依据已验证 info.format，JPG 合并 JPEG；不支持/损坏项不参与勾选。任务 API 与媒体写入核心保持不变。

动效限于展示：步骤变化淡入，轮询同一状态不重复；原始请求意图版本仍是异步提交门槛，动画不阻塞或代替真实进度。减少动态效果保留最终状态、键盘和取消能力。


### 事前计划与命名边界
右侧简短摘要通过明确点击打开完整处理计划；读取当前选择、预设、尺寸与目录，不启动任务。桌面宽面板与手机单列共用固定标题/返回区及可滚动正文，支持 Escape 和焦点返回。浏览器导入只显示服务副本位置，并保留 export-only。

默认保留实际文件名/扩展名和相对目录，不修改网站引用。当前无批量重命名功能；后续如增加，优先仅限导出模式、默认关闭，展示规则示例并先检查冲突，源文件和备份名称不受影响。


### 普通 PDF 可选支持与归档语义（当前实现）
PDF是明确的文档候选类型，扫描/浏览器文件与文件夹导入、按PDF类型勾选、CSV和持久任务记录均支持。普通静态、非加密PDF使用pikepdf子进程，只做结构/Flate重压，所有画质预设同一策略、尺寸不作用。PDF保持同扩展名与相对目录，默认导出；备份覆盖复用现有验证/指纹/原子替换/恢复冲突检查，后端拒绝含PDF的无备份覆盖。浏览器导入仍只导出。

明确跳过加密/权限限制、签名、表单、脚本动作、所有注释（含链接）、附件和外部文件流、复杂过滤器、结构警告/损坏；不解密或移除限制，不恢复损坏。支持普通、Flate和JPEG流；JPEG保持原码。64MiB、1000页、50000对象、单流32MiB、总解码128MiB限制；检查30秒、压缩90秒，Windows Job Object/Linux RLIMIT_AS限制子进程1GiB。检查页数/页框/旋转/有序内容和流摘要、qpdf语法；不宣称绝对视觉/语义等价。

结果仅提供有鉴权、受路径/指纹约束的PDF附件下载，响应nosniff；网页不嵌入PDF。无收益复制/保留原件，失败列出真实原因，取消与重复处理沿用核心保护。可选依赖缺失时有当前平台安装指引。

“清空/已清空”现更名为“归档/已归档”，现有接口和持久记录兼容；只整理列表，不自动30天删除任务/报告/源副本/备份。界面明确不释放这些文件空间；可随时恢复。


### 单条归档任务记录彻底删除
GET /api/tasks/{id}/deletion-preview只读返回条目/结果/备份数量与record_version；POST /api/tasks/{id}/delete-record要求严格布尔confirm=true及合法版本。只允许32hex任务标识、终态、未固定且已归档记录。原始任务JSON及归档/固定标志形成版本；事务内重新校验，不接受陈旧确认。worker_lock→engine.lock→SQLite BEGIN IMMEDIATE顺序与写入/恢复保持一致，任务线程未结束也拒绝，避免记录复活。重复已成功请求在合法确认下幂等返回already_absent。

仅删该task记录与task list_state，保留其他任务、目录权限/排除范围、扫描记录和processed重复指纹；清理已结束任务对应内存引用。所有源/输出/备份/原始导入副本与已保存报告不动。旧任务API/报告/预览/恢复不再可用；UI清掉正在展示的同一结果。导入manifest的sealed永久表示曾用于任务，删除前兼容补sealed，unused/discard/clear_unused仍保护，重启不解除。

删除是明确的逐条确认：说明失去工具内报告/预览/恢复、备份如有需手动恢复、无备份如实说明，不承诺释放媒体或立即缩小SQLite文件。取消、Escape、重名路径及其他任务均不受影响。保留token/Origin/Host/Fetch-Metadata/JSON校验；前端通过native dialog固定标题/按钮和中间滚动实现两种语言窄屏可达。


### 详情展示真实性
详情摘要的结果大小、节省和预览须有result_fp及已采用结果状态，不使用初始化result_size冒充失败结果。无收益使用原件字节/信息，标注尝试参数未采用；duplicate未再编码，展示任务设置；restored用恢复后原件信息和大小，历史参数单独标原处理参数/原输出尺寸。缺实际参数不得把任务配置称实际编码。保留无原件不对比、PDF仅下载和篡改/丢失预览错误。

默认界面以标签/值展示，原始JSON放到默认收起技术详情。标题固定，仅叉号但保留44px与可访问名称；内部正文滚动，关闭/Escape停止视频并恢复焦点。所有文字仍>=12px，中英文长标签通过换行和断点适配。
